### Pokopia Housing Grouper

I was getting tired of having to navigate between different Serebii pages to see what furniture items would double count for categories/what pokemon have shared interests. Has a (mostly) complete dataset as of April 19th (pre-Sableye). 

### Local Dev

`npm install` && `npm run dev`, will start at localhost:3000
